# personal-adblock-filterlist

Personal browser cleanup rules and userscripts.
Stable userscripts include [`reddit_safari_back_button_fix.user.js`](https://raw.githubusercontent.com/usernomom/personal-adblock-filterlist/main/reddit_safari_back_button_fix.user.js), which restores the Safari/Macaque back-trap escape behavior across fresh, BFCache-restored, and same-document history traversals and cleans Reddit JavaScript-challenge parameters, including `jsc_token`.

Regression-test documentation: [`tests/README.md`](tests/README.md).
