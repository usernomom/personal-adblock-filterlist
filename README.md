# personal-adblock-filterlist

Personal browser cleanup rules and userscripts.
Stable userscripts include [`reddit_safari_back_button_fix.user.js`](https://raw.githubusercontent.com/usernomom/personal-adblock-filterlist/main/reddit_safari_back_button_fix.user.js), which tracks Reddit's JavaScript-challenge history entry, preserves Safari's standalone-tab escape behavior, and for externally referred short-history tabs automatically returns from Reddit's pushed challenge entry to the clean first entry so Safari's next Back can use its native parent-tab behavior.

Regression-test documentation: [`tests/README.md`](tests/README.md).
